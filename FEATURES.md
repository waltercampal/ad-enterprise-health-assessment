# Features

## Current Features

- Domain Controller Inventory
- Forest Information
- Domain Information
- FSMO Roles
- Site Topology
- Replication Health
- DNS Assessment
- Time Service (W32Time) Health
- SYSVOL / DFSR Health (FRS migration state)
- Group Policy Assessment (SYSVOL/AD version consistency, orphaned GPOs)
- Security Baseline (SMBv1, LAPS, privileged account hygiene)
- Server Configuration (OS version, disk space)
- Event Log Analysis (Directory Service, DNS Server, DFS Replication)
- Migration Readiness (Windows Server 2016 -> 2022): schema version, legacy
  OS blockers, FRS/DFSR state, co-located server roles
- Infrastructure Score (severity-weighted, 0-100)
- HTML Reports
- CSV Exports
- Executive Summary (plain text)

## Planned Features

- Certificate Services (dedicated assessment, beyond co-location detection)
- DHCP Assessment
- File Services
- IIS
- SQL Server
- Azure Integration
- Entra ID Assessment
- Interactive/portal-style HTML reporting
