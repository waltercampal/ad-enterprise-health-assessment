# Features

## Current Features

**Foundation**
- Forest & Domain Information
- FSMO Roles
- Domain Controller Inventory
- Site Topology
- Active Directory Replication Health
- SYSVOL / DFSR Health
- DNS Assessment
- Group Policy Inventory
- Security Baseline (password policy, krbtgt age, Domain Admins, delegation, stale accounts)

**Infrastructure**
- DHCP Assessment
- Certificate Services (AD CS)
- File Services & Disk Capacity
- DFS Namespace Health
- Event Log Analysis
- Windows Services Health

**Hybrid Identity**
- Microsoft Entra Connect Sync Status
- PTA Agent Status
- Cloud Sync Agent Status
- Microsoft Entra ID Tenant Assessment
- Conditional Access Review

**Reporting**
- Executive HTML Dashboard with Infrastructure Health Score
- Per-area traffic-light status (Healthy / Needs Review / Critical)
- CSV export for every module
- Demo/fictitious data generator for safe showcasing

## Planned Features

- Historical trend tracking across scheduled runs
- Power BI integration
- Azure resource assessment (beyond Entra ID)
